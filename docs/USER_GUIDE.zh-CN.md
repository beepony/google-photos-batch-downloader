# 使用指南

[English](USER_GUIDE.md)

## 1. 开始之前

- **磁盘空间**：至少要有导出大小那么多的可用空间（Takeout 会显示，比如“330.68GB”）。如果还打算全部解压，需要再多准备一份空间。
- **下载位置**：Chrome 设置 → 下载内容 → 位置。备份要放到移动硬盘的话，就选硬盘上的文件夹。插件不会弹出“另存为”窗口。
- **网络流量**：300GB 的导出就要消耗 300GB 流量。如果网络按流量计费，请设置**流量上限**（见下文）。
- **过期时间**：Takeout 下载链接一般一周左右过期，插件弹窗里会显示具体日期。

## 2. 创建导出

1. 打开 [takeout.google.com](https://takeout.google.com) → **取消全选** → 只勾选 **Google 相册**。
2. **下一步** → 传送方式选“通过电子邮件发送下载链接”，频率选“导出一次”，文件类型选 `.zip`，文件大小随意。
   分卷越大文件越少；网络慢或不稳定时 2GB 最稳，网络快且稳定时 10–50GB 也没问题。
3. 点**创建导出**，等待邮件（几分钟到几天不等）。

## 3. 下载全部分卷

1. 打开邮件里的链接，或在 Takeout 里打开**管理导出**。Google 可能会要求登录验证。
2. 页面右下角会出现一个浮窗：**一键下载全部 N 个**，点它。
3. 进度可以在浮窗、工具栏图标（显示百分比）和插件弹窗里查看。

弹窗里每个小方块代表一个分卷：

| 颜色 | 含义 |
|---|---|
| 青绿 | 已完成 |
| 橙色（逐渐填满） | 下载中 |
| 斜条纹 | 等待重试 |
| 红色 | 多次尝试后失败 |
| 米色 | 排队中 |

鼠标悬停在方块上可以看到文件名或错误原因。

## 4. Google 再次要求验证身份时

Google 规定：验证通过后大约 20 分钟内可以开始新的分卷下载，过期后再开始新分卷就要重新验证。这是 Google 的安全机制，和页面是否闲置无关，保持页面打开或刷新都不能延长。已经开始下载的分卷不受影响，会一直下完。

插件的做法是**减少验证次数**：每次验证后的约 17 分钟内，集中启动最多 N 个分卷（设置里的**验证后集中启动**，默认 6），之后恢复正常并发。弹窗里会显示“预计约 HH:MM 需要再次验证”。

需要验证时：

- 队列会暂停（已经在下载的分卷不受影响）。
- 插件会切到 Takeout 页面，播放提示音，并弹出一个不会自动消失的通知（点它即可回到页面）。工具栏图标显示 **!**。
- 用密码或通行密钥完成验证。建议给 Google 账号开启[通行密钥](https://myaccount.google.com/signinoptions/passkeys)，用 Touch ID / Windows Hello 几秒就能完成。
- Takeout 页面带着新的验证状态重新加载后，下载会自动继续。如果没有继续，在弹窗里点**已完成验证，继续**。

## 5. 设置（弹窗里的 ⚙）

| 设置 | 作用 |
|---|---|
| **同时下载 N 个** | 并行下载的数量。默认 3；网络慢时建议 1–2。 |
| **验证后集中启动** | 每次验证后约 17 分钟内最多同时启动几个分卷，默认 6，可选关闭 / 4 / 6 / 8。数字越大验证越少，但带宽会被分摊。 |
| **保存到 下载目录/…** | Chrome 下载位置里的子文件夹。留空则直接存在下载位置里。旁边的 **打开下载目录** 可一键在访达 / 资源管理器中打开。 |
| **本轮流量上限** | 下载到这么多 GB 后暂停，点**继续**开始下一轮。0 表示不限。 |
| **只在…下载** | 每天的下载时间段，比如 00:00–08:00，跨午夜也可以。 |
| **下载时防止电脑休眠** | 通过 Chrome 的电源接口阻止电脑休眠，但屏幕仍可能锁定。 |
| **通知我** | 全部完成、达到流量上限或需要验证时发送系统通知。 |
| **需要验证时播放提示音** | 需要验证时播放一声短提示音。 |
| **界面语言** | 跟随浏览器、中文或 English，也可以用顶部的 中 / EN 按钮切换。 |

## 6. 校验下载结果

**更多操作 → 导出校验脚本**，会把 `verify-takeout.sh` 保存到 zip 文件所在的文件夹。在终端里运行：

```bash
cd "/Volumes/我的硬盘/Google Takeout"
bash verify-takeout.sh
```

脚本会用 `unzip -t` 逐个测试分卷，每个分卷输出一行（`OK`、`BAD` 或 `MISSING`），最后输出汇总，
并保存报告 `verify-report-<时间>.txt`。退出码为 0 表示全部正常。

对于 `BAD` 或 `MISSING` 的分卷，在**更多操作**的分卷输入框里填编号（比如 `7, 12-14`），然后点**重新下载**。

Windows 上可以在 Git Bash 或 WSL 里运行脚本，或者在资源管理器里逐个打开 zip 检查。

**导出清单 CSV** 会生成一个表格，列出每个分卷的状态、文件名、大小、尝试次数和错误信息。

## 7. 已经手动下载过一部分

- **同一个浏览器**：不用做任何事。Chrome 下载记录里已完成或正在下载的分卷会被自动识别。
- **其他浏览器或其他电脑**：把文件复制到下载文件夹，然后在**更多操作**里填写这些分卷的编号，点**标记为已有**。校验脚本仍然会检查这些文件。

## 8. 常见问题

| 问题 | 解决方法 |
|---|---|
| Takeout 页面上没有出现浮窗 | 确认打开的是列出所有分卷的“管理导出”页面，然后刷新；检查插件是否已启用。 |
| Chrome 提示“已阻止自动下载多个文件” | 一般不会出现。如果出现：点地址栏里的图标，选择“始终允许 takeout.google.com”。 |
| 一直要求重新验证 | Google 约每 20 分钟要求验证一次才能开始新分卷。调大**验证后集中启动**、开启通行密钥，或导出时选更大的分卷（如 50 GB），都能减少验证次数。 |
| 某个分卷一直失败 | 先检查磁盘空间，再点**重试失败项**。仍然失败的话，过几个小时再重新下载这个分卷。 |
| 提示“磁盘空间不足” | 清理空间或更换下载位置后，点**继续**。 |
| 链接已过期 | 需要重新创建导出。新导出的分卷划分通常和旧的不一样，所以一般不要把旧文件标记为已有，重新下载更稳妥。 |
| 暂停并提示“已达到本次流量上限” | 这是预期行为。点**继续**开始下一轮，或把上限设为 0。 |

## 9. 备份完成之后

校验脚本输出 `ALL GOOD` 后，先把 zip 文件（或解压后的文件）妥善保存好，再考虑删除 Google 相册里的内容。
建议在另一块硬盘上再存一份。如果要删除账号里的照片，请先在手机上关闭 Google 相册的备份与同步，
否则手机可能会再次上传这些照片。

插件本身不会删除 Google 上的任何内容。
